# Creative foundation — Sea, Ship, Math

Updated: 5 October 2026. **Living Atlas A/B is approved as the foundation.** The
user explicitly requested promotion to the actual homepage/blog, updated
documentation and a commit. This file preserves the creative standard for the
work that follows, not a pending permission request.

## What the user rejected

Review set 01 was not approved. The notebook barely looked different and the
explicit ship controls felt too simple/childish. The user wants a coherent,
impressive experience that rewards both a casual and technically informed
visitor. They permitted replacing the experiments and later requested removal
of superseded files. That rejected UI has been removed.

Do not resume the old Wind-versus-Helm choice. Its shortcomings remain recorded
in the research. Small bundles and successful builds remain necessary evidence,
but they do not substitute for the user's creative judgment.

## Creative standard

- **Sea, Ship, Math** are the soul; A serves the main site, B the publication,
  and C an optional discovery.
- Make the first impression work without a tutorial or input request. Ask for
  deliberate interaction only when it produces a rich, legible consequence.
- Give the notebook an unmistakable composition of its own before anything moves.
- Design desktop and mobile deliberately. Core impact works without sensor
  permission; optional motion input has to earn its place.
- Let backend work provide visible value: a reproducible sea and its printable
  edition already do this. Real observations are a later possibility, not current
  functionality.
- Spend a measured performance budget on the signature moment. Preserve readable
  content, ordinary navigation, reduced motion and a designed fallback.
- Keep documentation sufficient for another model to continue: decisions,
  contracts, files, next steps, evidence and limitations.
- Commit the approved foundation as requested. Keep future unselected visual or
  interaction experiments uncommitted until the user approves those choices.

## Approved direction

**The sea becomes its own engineering drawing.** One mathematical surface is
rendered as light and water, then revealed as contour/section geometry. Surface,
ship pose and printed plates share the same field. Fine light detail and wake
remain rendering approximations. Ordinary scrolling tells the story and direct
navigation remains available.

The notebook is a large-format maritime atlas: oversized editorial type, ink,
engraved plates, folio rails and deliberate whitespace. It shares the geometry
and identity with A while using different page composition and colour.
