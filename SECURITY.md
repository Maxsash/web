# Security

Report a vulnerability by email to yash@maxsash.com. Please do not open a public
issue for it. Machine-readable contact details are at
[/.well-known/security.txt](https://www.maxsash.com/.well-known/security.txt).

This is a static-content site. It has no accounts, no database, no cookies, no
user-submitted content and no secrets in the client or in this repository. The only
server-side input is a sea seed (eight hexadecimal characters), validated before use.
